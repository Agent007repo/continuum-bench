# ContinuumBench

What does it cost, in accuracy, latency and measured energy, to run a language model on a laptop GPU, on a CPU acting as a small edge server, or behind a router that escalates only hard requests? ContinuumBench answers that for six quantised models on one Apple M1 Max, under a protocol frozen before data.

Start with the [results](results.md), then the [method](method.md) and [limitations](limitations.md). The full report is [`paper/report.pdf`](https://github.com/Agent007repo/continuum-bench/blob/main/paper/report.pdf).
