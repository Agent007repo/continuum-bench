# How this was built

Samarth supplied the research brief and constraints. AI coding assistants produced the current code and draft documentation under that direction. Human annotation, Mac benchmark execution, review of design choices and final wording review are pending. We will update this account only when those activities have happened. No generated annotation is a human gold label.

These are independent projects. They are not affiliated with, endorsed by, or built using internal material from TU Delft, TU/e, TNO, the f-inference consortium or the LLM4LM consortium. We use public information and original synthetic examples.
